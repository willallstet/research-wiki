## Software & web projects

- **imageGit** — [github.com/willallstet/imageGit](https://github.com/willallstet/imageGit),
  presented via a diagram of "a git command line history of an image" — treating
  an image's edit history as version-controlled commits (`index.html:52 @1436a13`).
  Ties to [[archives-and-wikipedia]] and [[ai-and-machine-vision]].
- **Poetic Network Faculties** —
  [poetic-network-faculties.up.railway.app](https://poetic-network-faculties.up.railway.app/)
  (`index.html:62 @1436a13`).
- **Local Are.na vector search** — [arena-finder-folders](https://github.com/willallstet/arena-finder-folders),
  a local vector search over Are.na (`index.html:75 @1436a13`). Ties to
  [[archives-and-wikipedia]] and [[ai-and-machine-vision]].
- **Tangible Media Group library prototype** — an embodied way of navigating a
  physical library using vector search, with the MIT Media Lab
  [Tangible Media Group](https://www.media.mit.edu/groups/tangible-media/overview/)
  (`index.html:82 @1436a13`). See [[affiliations]].
- **wikiAssociations** — a scrolling feed of Wikipedia-sourced images,
  [willallstet.github.io/wikiAssociations](https://willallstet.github.io/wikiAssociations/)
  (`index.html:72 @1436a13`). Ties to [[archives-and-wikipedia]].
- **hypersynchronism.com** — [hypersynchronism.com](https://hypersynchronism.com/)
  (`index.html:68 @1436a13`).
- **Fortune teller** — an old-timey-terminal web toy,
  [fortuneteller-23ce6.web.app](https://fortuneteller-23ce6.web.app/)
  (`index.html:88 @1436a13`).
- **"a nice place 2 stream"** — [a-nice-place-2-stream.netlify.app](https://a-nice-place-2-stream.netlify.app/)
  ("infinite entertainment value") (`index.html:90 @1436a13`).
