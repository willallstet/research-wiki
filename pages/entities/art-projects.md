## Software & web projects

- **Poetic Network Faculties** —
  [poetic-network-faculties.up.railway.app](https://poetic-network-faculties.up.railway.app/)
  (`index.html:59`).
- **Local Are.na vector search** — [arena-finder-folders](https://github.com/willallstet/arena-finder-folders),

  [[archives-and-wikipedia]] and [[ai-and-machine-vision]].

  (`index.html:79`). See [[affiliations]].

  [willallstet.github.io/wikiAssociations](https://willallstet.github.io/wikiAssociations/)
  (`index.html:69`). Ties to [[archives-and-wikipedia]].
- **hypersynchronism.com** — [hypersynchronism.com](https://hypersynchronism.com/)
  (`index.html:65`).
- **Fortune teller** — an old-timey-terminal web toy,
  [fortuneteller-23ce6.web.app](https://fortuneteller-23ce6.web.app/)
  (`index.html:85`).
- **"a nice place 2 stream"** — [a-nice-place-2-stream.netlify.app](https://a-nice-place-2-stream.netlify.app/)
